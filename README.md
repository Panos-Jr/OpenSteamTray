# Requirements 

You'll need either SteamTools, or OpenSteamTool installed, for this to work.

https://steamtools.net - SteamTools

https://github.com/PandaQuQ/OpenSteamTool/releases - OpenSteamTool (this is a working fork, as the original has not been updated yet to address recent issues)

Hubcaps Manifest API KEY - https://hubcapmanifest.com/api-keys/stats (the app should let you know if your key expires or is invalid regardless, you can set the key in options)

# Setup

Extract `OpenSteamTray.zip` from [Releases](https://github.com/Panos-Jr/OpenSteamTray/releases) and run `setup.bat`, then you can run OpenSteamTray.exe, it should show up on your Windows Tray.

<img width="218" height="140" alt="image" src="https://github.com/user-attachments/assets/2da5b5f4-e6b1-4444-a1f1-54cef7e2aa63" />

When you're using Steam app, you can click on a game, in the Steam Store, and a pop-up should appear, asking if you want to add the manifest files for the game. This is timed, so you'll have to decide in the time limit, 
otherwise game will be excluded.

<img width="340" height="258" alt="image" src="https://github.com/user-attachments/assets/c010426d-0eb2-43a8-8624-113129d13c05" />
